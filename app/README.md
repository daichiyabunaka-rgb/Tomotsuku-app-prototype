# ともつく！（Tomotsuku・総合版）

**「ともつく！」シリーズ12アプリ＋ユーザー作成ハブを1本のアプリで横断利用できる、総合版（プラットフォーム型）プロトタイプです。**

- Phase 1: 内蔵12ハブ（飯とも！/犬とも！/釣りとも！/ニーアキャット/コスとも！/走りとも！/キャンとも！/音とも！/湯とも！/スポとも！/雀とも！/ゲーとも！）を「ハブ」として切り替え可能
- Phase 2: 「次のハブのリクエスト」「機能のリクエ스트」ボード（ユーザー投票で需要を集める）
- Phase 3: 「ハブをつくる」ウィザード（ユーザーが設定ベースで新しい趣味ハブを申請→運営審査→承認で全ユーザーのハブ一覧に即時表示。Roblox型UGC）※要 `hub_configs` テーブル（0014相当）

詳細はリポジトリルートの [README](../README.md) と [要件定義書](../docs/要件定義書_ともつく総合_v1.md) を参照。
